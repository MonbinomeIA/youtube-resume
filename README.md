# Résumer une vidéo YouTube avec Claude Code

Tu donnes le lien d'une vidéo YouTube à Claude Code. Il lit les sous-titres et te prépare une note
complète : les idées, les outils cités, les étapes, les conseils. Ensuite, tu lui poses tes
questions sur la vidéo, même plusieurs jours après.

Il faut avoir **Claude Code** sur ton ordinateur.

## Installer (1 minute)

Ouvre Claude Code et colle ce message :

```
Installe le skill youtube-resume depuis https://github.com/MonbinomeIA/youtube-resume : copie SKILL.md dans ~/.claude/skills/youtube-resume/ et installe yt-dlp s'il manque.
```

Claude Code fait tout tout seul. Quand il a fini, ferme-le et rouvre-le.

## Utiliser

Colle le lien de la vidéo après `/youtube-resume` :

```
/youtube-resume https://www.youtube.com/watch?v=...
```

Puis pose tes questions : « Il disait quoi sur les prix ? », « Explique-moi l'étape 3 ».

La vidéo doit avoir des sous-titres (même automatiques), en français ou en anglais.
